# 設計判断の記録と引き継ぎメモ

要件定義書（`docs/requirements.md`）の「なぜそうしたか」と「次に何をするか」を残す。
新しいセッションで作業を再開するときは、まず本書と要件定義書を読むこと。

## 1. 決定事項と理由

| # | 決定 | 理由 | 日付 |
|---|---|---|---|
| D1 | 入力は USB PD がメイン。20V を優先して要求する。DC ジャックはフットプリントのみ | 手持ちの充電器が使えて取り回しが良い。PD のコストは 2 枚で 500〜1,000 円程度（大半は Extended Parts の追加料金という固定費）で、AC アダプタを別に買うより安い。逆流・サージは PRT-04/05 と IN-08 で対策する | 11-03〜05 |
| D2 | 出力は 0.8〜12V / 2A の可変 1ch ＋ 固定 3.3V/5V。左右のレールごとにジャンパで選ぶ | ブレッドボードの両レールを活かすため | 11-03 |
| D3 | 表示は OLED | ロック・CV/CC・保護の状態をまとめて表示できるため | 11-03 |
| D4 | ソフトロックはエンコーダの長押しで切り替える。確認操作は試作してから必要なら足す | まず簡単に作り、FW を状態遷移で作って拡張できるようにしておく（UI-09） | 11-03 |
| D5 | ブレッドボードに直接刺す形（MB102 互換の配置） | ユーザーの希望。ブレッドボード接点の電流容量は利用者が管理する | 11-03 |
| D6 | CC 制限は**任意の電流で**、Rev.A から入れる。ただし切り離せる設計にする（VAR-06a） | 固定の CC にしてもコストはほぼ変わらない。CC が最もリスクの高い回路なので、早く実機で検証した方が試作回数が減る。だめでも電圧可変＋トリップ遮断の電源として使える | 11-05 |
| D7 | SMD はすべて JLC（Economic PCBA、片面）、THT は手はんだ | ユーザーの手元にホットプレートやホットエアがない | 11-04 |
| D8 | PCBA は毎回 2 枚（基板は 5 枚） | Economic PCBA の最小数が 2 枚（発注時に再確認すること）。電源の試作は壊しやすいので予備にもなる | 11-05 |
| D9 | **コストの方針：部品代より試作回数の削減を優先する**。目標は 1 回 9,000 円以下、試作 3 回以内 | 試作 1 回で数千円と数週間かかる。検証しやすい部品（SPICE モデルがあるなど）を優先する（CST-00） | 11-05 |
| D10 | 回路図は Claude がコードベースのツールで書き、最終的には KiCad で管理する。ツールは未定（tscircuit / EasyEDA MCP / SKiDL など） | AI が設計し、人がレビューする流れにするため。ツールは検証パイプライン（6.5 節）に組み込めるかで選ぶ | 11-03〜05 |
| D11 | 検証パイプラインを作る（ERC/DRC、ネットリスト独自ルール、ピン照合、BOM チェック、設計計算、ngspice、FW のホスト上テスト） | コードと同じように機械的なフィードバックループを回して、実機に持ち込むミスを減らすため | 11-05 |
| D12 | 部品選定をツール選定より先に行う | ツールの評価では「選んだ部品を取り込めるか」が重要なので、実際の部品で試すため | 11-05 |
| D13 | 固定 5V / 3.3V 出力は「ついでに出せるなら出す」もの。降圧は内部用の 5V 1 つだけにし、3.3V は 5V からの LDO。目安は 5V 1A / 3.3V 0.2A（FIX-01/02 を推奨に変更） | ユーザーの判断：固定出力のために降圧コンバータを増やすほどの価値はない。部品点数と基板面積も減る | 11-05 |
| D14 | OLED は 0.96" SSD1306 の 4 ピン I2C モジュール（Q3） | ブレッドボードの幅にエンコーダと並べて収めやすい。ユーザーも同意 | 11-05 |
| D15 | 5V しか出ない入力のときは VAR 出力を禁止する（Q8、IN-04） | 出せるのは 3V 程度までで使い道が少ない。充電器の電流能力もわからず、MCU が電圧低下でリセットするおそれがある | 11-05 |

## 2. コストの概算（2026-11 時点・未検証の値を含む）

- 試作 1 回あたりの固定費：基板 $2〜5、PCBA の段取り費 $8（Economic）、Extended Parts は**1 種類につき $1.5〜3**（情報源によって値が違う。見積もり画面で確認すること）、日本への送料と関税 $10〜25
- Preferred Extended Parts は、Economic PCBA なら部品ごとの追加料金がかからない
- 構成ごとの総額の目安（PCBA 2 枚）：PD なし・CC なし 5,000〜6,500 円 / PD のみ 6,000〜7,000 円 / PD＋CC 7,000〜9,000 円
- 確認できた価格：CH224K（C970725）は 1 個 約 $0.5、在庫 約 1 万個。それ以外は知識ベースの概算

## 3. 環境についてのメモ（Claude Code のクラウドセッション）

- 2026-11-06 にネットワーク設定が更新され、`jlcpcb.com`、`lcsc.com`（`wmsc.lcsc.com` を含む）、`www.ti.com`、`cdfer.github.io` に Bash（サンドボックス）から届くようになった。**スクレイピングはサンドボックスから行う**（ユーザーの指示）。WebFetch は名前解決できないことがあるので、curl か Python を使う
- ネットワーク設定はスマホのアプリからは変更できない（ユーザー談）。PC のブラウザから行う
- 取得の手順は `docs/parts-selection.md` の 7 章
- ngspice は `apt-get install -y ngspice` で入る（ngspice-42）。コンテナが作り直されると消えるので、毎回入れ直す
- 作業ブランチ：`claude/requirements-v0.2`
