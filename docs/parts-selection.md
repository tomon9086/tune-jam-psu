## 2. VAR 降圧 IC（最優先）

### 2.1 必須条件から導いた選定の基準

- **入力耐圧**：PD は 20V（最大 21V）。サージのときは TVS のクランプ電圧（SMBJ22A で 約 35.5V）までかかる → **絶対最大 36V 以上が欲しい**（要件は 28V 以上）
- **最小オン時間**：20V → 0.8V では、デューティ比が 4%。400kHz ならオン時間 100ns が必要 → **最小オン時間は 80ns 以下（最大値で）が必要**
- **CC で出力 0V 付近まで下げるとき**：FB 注入方式の CC で短絡に近い負荷になると、オン時間がさらに短くなる。最小オン時間で止まったときに周波数を下げる（または電流制限で止まる）IC でないと、電流が暴走する
- **FB 注入**：FB の基準電圧より低い出力も、注入電流で作れる（式は 2.3 節）。基準電圧 ≤ 0.8V は必須ではない
- **軽負荷**：PFM / パルススキップで、インダクタの逆電流を流さないこと（PRT-04 の補助）

LMR33630 の補足：
- 絶対最大の VIN 38V、PG 端子 22V（✅ データシートの抜粋）
- 電流制限：ハイサイド 3.85〜5.05A（4.5A typ）、ローサイド 2.9〜4.1A（AP-Q1 版の値 ✅）。FB < 0.4V でヒカップに入り、間隔は 94ms ✅
- 最小オン時間で止まると周波数を下げ、オン時間は一定のまま（✅ データシートの記述）→ CC で出力を 0V 近くまで下げても制御できる見込み
- FB 注入方式の CC では、ループが FB を 1.0V に保つので、通常はヒカップに入らない。CC ループが追いつく前にハードウェアの電流制限が働くと、FB が下がってヒカップに入ることがある（これは保護として許容する）
- **SPICE モデル**：TI は PSpice モデルを出しているが、暗号化されている可能性が高く、ngspice では動かない見込み（KiCad フォーラムでも未解決）。VER-07 は**平均化モデル（自作）で ngspice を回し**、ベンダーのモデルは PSpice for TI で手動で答え合わせする、という分担を提案する
- **在庫の懸念**：JLC の在庫が 1,272 個（スニペットの値）で、MFG-05 の目安（1,000 個以上）ぎりぎり。1 枚に 2 個使うので、発注前に必ず確認する。代替は LMR33630ADDA（チューブ品、C2866787）と LMR33640ADDAR

### 2.3 VAR の定数の目安（P2 で計算スクリプトにする）

- FB 注入の式（オペアンプの出力 Vctl が Rinj を通して FB に入る場合）：
  `Vout = Vref·(1 + R1/R2) + (Vref − Vctl)·R1/Rinj`
  Vctl = 0V で最大電圧（約 13V）、Vctl を上げるほど出力が下がる。Vctl はおよそ 0〜3.3V。DAC 12bit なら約 3.2mV/LSB で、VAR-03（10mV）を満たす
- インダクタ：400kHz で L = 10µH のとき、リップル電流が最大になるのは Vout = 10V（VIN 20V）で 約 1.25Ap-p、12V/2A のときピーク 約 2.6A。**飽和電流は電流制限の 4.5A 以上**を選ぶ（短絡時の対策）→ 7×7〜8×8mm のシールド型。品番は未定 ❓
- 効率：12V/2A・20V 入力で 90% 前後の見込み（データシートのグラフで P2 に確認）→ NF-01 の 85% は満たせる見込み

CH224A を推す理由：
- レジスタ 0x50 で「今の PDO で使える最大電流」（50mA 単位）が読める ✅。入力電力の上限（後述）を FW で守るのに使える
- レジスタ 0x60〜0x8F で Source Capabilities 全体を読める ✅ → IN-02 の「20V → 15V → 12V → 9V の順に下げる」を FW で確実に行え、IN-07（交渉結果の表示）も満たせる
- レジスタ 0x0A で要求電圧を切り替えられる ✅
- 注意：I2C は「抵抗 1 本での設定」のときだけ有効 ✅。USB-A 出力の充電器では電流のレジスタが無効 ✅
- **CH224K とのピン互換は未確認** ❓。同じ ESSOP-10 なので、互換ならフットプリントを共通にして在庫切れの保険にする

**入力電力の予算（新しい論点）**：全出力を最大にすると VAR 24W ＋ 5V 5W ＋ 3.3V 1.65W ＋ 内部 約 0.5W ≈ 31W、効率 90% で入力 約 35W。20V/3A（60W）の充電器なら足りるが、30W 以下の充電器では足りない。**PDO の電流から、VAR の電流上限を FW で自動的に下げる**ことを IN-03 に追加することを提案する

### 3.3 短絡検出・OVP（PRT-02/03）

- **LM393DR2G（C7955、Basic ✅）**：応答時間 約 1.3µs（小さいオーバードライブのとき ❓）で、10µs の目標には十分。電源 2〜36V
- 1 回路目：INA180 の出力 > 3A 相当 → VAR 降圧の EN と出力スイッチのゲートを引き下げる。ラッチは正帰還か、MCU の GPIO でリセットする方式を P2 で決める
- 2 回路目：出力の過電圧（13.5V 相当）のハードウェアクランプ（PRT-03 の推奨部分）
- 同相入力の上限は VCC − 1.5V なので、LM393 は 5V 電源にし、入力は 3.5V 以下に収める

### 3.4 補助電源（Q5：決定済み、D13）

固定 5V / 3.3V 出力は「ついでに出せるなら出す」もの（ユーザーの判断）。**降圧は内部用の 5V 1 つだけ**にする。

- **5V**：LMR33630ADDAR（VAR と同じ型番）。内部の 5V（INA180、TLV9062、LM393、OLED）と固定 5V 出力（SY6280 で 1A 程度に制限）をまかなう。IC は 3A まで流せるので余裕がある
- **3.3V**：AMS1117-3.3（C6186、Basic の見込み ❓）を 5V から。内部の 3.3V（MCU、INA226、OLED など 約 50mA ❓）と固定 3.3V 出力（SY6280 で制限）
  - 損失：(5 − 3.3) × (0.2 + 0.05) ≈ **0.43W**。SOT-223 で銅箔を広めにとれば（θja 約 60℃/W ❓）+26℃ 程度で、NF-02（+40℃ 以内）に収まる見込み
  - 固定 3.3V の上限（0.2A 程度）は、P2 で熱の計算をして決める。SY6280 の電流制限の下限が 0.4A なので、0.2A に絞るなら別の方法（ポリスイッチや、LDO 自体の電流制限に任せる）を検討する ❓
- 3.3V の固定出力が短絡すると MCU の電源も引っ張られるので、MCU の電源と固定出力の間は電流制限で切り離す
- 降圧は VAR と 5V の 2 つになり、面積の懸念はかなり減る

### 3.6 出力スイッチ・逆流防止（**要件定義書の候補を変える必要がある**）

**問題**：8 章の候補「P-FET（AO3401 系）× 2」は、ゲートを GND に引いても Vgs = −Vout にしかならない。Vout = 0.8V では、しきい値（−0.5〜−1.3V）を超えられず ON にならない。VAR-01 の下限 0.8V を満たせない。

GND は左右のレールで共通（BB-03）なので、ローサイドのスイッチも使えない。

**提案**：N-FET（AO3400A、C20917、Basic ⚠️、30V、Vgs ±12V）× 2 をソース共通のバックツーバックにして、ハイサイドに置く。ゲートは VIN より高い電圧で駆動する。
- ゲート電源：補助降圧（5V 用）のスイッチノードから、ダイオードとコンデンサのチャージポンプで「約 2 × VIN」を作る（ダイオードは BAT54S など）
- Vgs は 10V 程度のツェナーでクランプし、AO3400A の ±12V を守る
- OFF：LM393（短絡）または MCU がゲートを引き下げる
- 損失：Rds(on) 約 20mΩ × 2、2A で 約 0.16W
- **リスク**：起動時と短絡時のゲートの挙動、チャージポンプの負荷を、ngspice で確認する（VER-07 に追加）。新しい未決事項 Q9 として扱うことを提案する
- 代替：ハイサイドの N-FET ドライバ IC（チャージポンプ内蔵）。ただし 0.8V 出力で動く安価な品を見つけられていない

### 3.10 THT 部品と OLED（Q3）

- **Q3：0.96" SSD1306 の 4 ピン I2C モジュールに決定（D14）**（約 27 × 27mm）。1.3" SH1106（約 35 × 33mm）は見やすいが、エンコーダと並べるとブレッドボードの幅（約 55mm）に収めにくい
  - 注意：4 ピンモジュールは、販売元によって **VCC と GND の順番が逆**のものがある。シルクにピン名を書き、購入する品を指定する
- エンコーダ：EC11 系（押しボタン付き、クリックあり）、手はんだ
- タクトスイッチ、ピンヘッダ、ジャンパ：手はんだ（国内で調達）

### 3.11 5V しか出ない入力のとき（Q8）

- **Q8 の推奨：Rev.A では VAR 出力を禁止する**（OLED に「入力 5V のため VAR は使えない」と表示する）
  - 理由：5V 入力では VAR の上限が 約 3V（VIN − 2V）になり、使い道が少ない。供給できる電流もわからない（USB-A の充電器では CH224A の電流レジスタが無効）ので、MCU が電圧低下でリセットするおそれがある
  - 固定 3.3V と表示は動く（LMR33630 の入力下限は 3.8V）。固定 5V は、降圧がドロップアウトして 4.5〜4.7V 程度になる見込み ❓
