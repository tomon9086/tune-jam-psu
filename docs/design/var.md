# VAR（可変出力）の制御回路の設計

定数の計算と要件との突き合わせは `hw/calc/var_network.py`（`make verify` で実行される）。

## 1. 構成

```
VOUT_SENSE ─R1 100k─┬─ FB（LMR33630、Vref 1.0V）
                    R2 500k
                    GND
DAC1 ─Ra 14.7k─┬─Rinj 2.7k─┐
               Rb 7.5k     ├─[INJ スイッチ]─ FB
               GND         │
CC アンプ ─ダイオード─Rcc──┘
```

- **Vset**：DAC1（0.2〜3.1V）を Ra/Rb で分圧して、Rinj から FB に注入する。DAC1 が高いほど出力が下がる。出力 0.58〜13.4V、分解能 3.6mV/LSB
- **CC**：CC アンプ（MCP6002）が「電流検出の電圧 + 0.2V」と DAC2 を比べ、電流が Iset を超えるとダイオード経由で FB に電流を流し込み、出力電圧を下げる。0.2V の下駄は、DAC が 0.2V 未満を出せないためで、VDDA の分圧で作る
- **INJ スイッチ**：Vset と CC の注入をまとめて FB から切り離す。MCU の GPIO で制御し、リセット時は OFF（プルダウン）

## 2. 起動の手順（INJ スイッチの理由）

LMR33630 のシミュレーションで、起動時から FB に注入して FB が約 0.95V に持ち上がっていると、IC がスイッチングを始めず、休止（ヒカップ）を繰り返して起動しなかった（`sim/lmr33630/README.md`）。データシートではヒカップの条件は「電流制限中に FB < 0.4V」だけで、モデルの癖の可能性が高い。ただ、起動時に FB が高いときの動作（プリバイアス起動）はデータシートに書かれていないので、実機で確かめずに頼るのは危ない。そこで次の手順にする。

1. 電源投入：INJ スイッチ OFF、出力スイッチ OFF。LMR33630 は Vref × (1 + R1/R2) = 1.2V に向けてソフトスタートする（約 4ms）
2. MCU が PG（LMR33630）を見て、立ち上がりを確認する
3. MCU が DAC1・DAC2 を設定してから、INJ スイッチを ON にする
4. 出力電圧が設定値に落ち着いたら、ユーザーの操作で出力スイッチを ON にできる
5. PG が落ちたとき（ヒカップなど）は、INJ スイッチを OFF に戻して 1 からやり直す

INJ スイッチは、VAR-06a（CC ループを切り離せること）の切り離し点も兼ねる。CC だけを切り離す 0Ω 抵抗も別に置く。

## 3. LMR33630 の最小オン時間

データシートの値は、DDA パッケージ（今回の LMR33630ADDAR）で **75ns（標準）／108ns（最大）**（RNX パッケージの 68/80ns とは違う）。20V → 0.8V を 400kHz で作るには 100ns が要るので、最悪値では足りない。ただし LMR33630 は最小オン時間に達すると周波数を下げて調整を続ける（データシート 8.4.3）。0.8V ではリップルが増えるので、P2 のシミュレーションで確認する。

## 4. CC ループのシミュレーション（2026-11-13、`sim/cc-loop/`）

LMR33630A は TI のモデル、INA180A1 と MCP6002 は特性を合わせた簡易モデル。Vset 5V、Iset 1A で、0.6ms に 2.5A 相当の負荷をつなぎ、1.6ms に外した。

| 案 | Rf / Cf | Chold | 反応 | Iset×1.1 以下まで | CC 中の電流 | 外した直後の最大 | 判定 |
|---|---|---|---|---|---|---|---|
| a | 4.7k / 10n | なし | 76µs | 486µs | 1.046A | 5.57V | NG |
| b | 10k / 2.2n | なし | 1µs | 78µs | 1.001A | 5.56V | NG（行き過ぎ） |
| c | 22k / 1n | なし | 1µs | 74µs | 1.001A | 5.57V | NG（行き過ぎ） |
| **d** | **10k / 2.2n** | **4.7n** | 1µs | 157µs | 1.001A | **5.009V** | **合格（採用）** |
| e | 10k / 2.2n | 10n | 1µs | 74µs | 1.002A | 5.006V | 合格（ただし前の電圧が 4.951V） |

わかったこと：
- **CC に入った直後の電流は、負荷の要求（2.5A）近くまで流れる。** CC アンプは 1µs で反応して降圧を止めるが、シャントの手前の出力コンデンサ（44µF）の放電は止められない。70〜160µs で Iset の 1.1 倍以下に戻る。ハードの短絡検出（3A）は別にある
- **CC を抜いた直後の行き過ぎ（+11%）は、注入が急になくなって降圧 IC が全開になるため。** ダイオードの後ろに Chold（4.7nF）を置き、注入をゆっくり減らすと +0.2% に収まった
- 最初の簡易モデルでは、オペアンプの出力が張り付いている間に内部の値がたまり続けて、反応が 150µs 遅れて見えた。内部の値を電源の範囲に制限して直した
